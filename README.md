# 괴물 중고마켓 MVP v0.2.1

Godot 4.x 기반 세로형 모바일 프로토타입입니다.

v0.2.1의 목표는 v0.2에서 이미 만든 숨은 가치·단서·판매자·구매자 시스템을 버리지 않고, **플레이어가 그 시스템을 직접 조사하고 판단하고 흥정하게 만드는 것**입니다.

## 핵심 루프

1. 장터의 매물 3개를 비교
2. 장터 전체가 공유하는 조사 기회 4회를 어디에 쓸지 결정
3. 외형 / 각인 / 작동·반응 / 출처 / 시세 중 필요한 정보만 조사
4. 구매 전에 진위·상태·예상 가치에 대한 가설 기록
5. 실제 제안가와 흥정 근거를 선택해 판매자와 최대 3회 협상
6. 구매 후 추가 검사 2회를 쓸지 결정
7. 전문 감정 300G를 지불할지, 감정 없이 판매할지 결정
8. 구매자 성향만 보고 전문 구매자 2명 중 누구에게 견적을 요청할지 선택
9. 견적 요청은 2회로 제한, 고물상은 즉시 매입가 공개
10. 판매 후 실제 정체 / 내 가설 / 흥정 / 정보 비용 / 판매처 선택을 복기
11. 같은 장터의 남은 매물로 돌아가 계속 거래

## v0.2.1에서 달라진 점

- 매물 하나를 눌러도 다른 두 매물이 사라지지 않음
- 매물 상태: 미확인 / 조사 중 / 거래 중 / 구매 완료 / 포기 / 판매 완료
- 장터 조사 기회 4회를 세 매물이 공유
- 처음부터 모든 단서를 공개하지 않고 조사 행동으로 추가 정보 획득
- 구매 전 가설: 진위 / 상태 / 예상 가치
- 흥정이 대사 선택에서 제안가 + 근거 방식으로 변경
- 발견한 단서를 실제 흥정 자원으로 사용
- 판매자 성격이 수락·카운터·거절 반응에 직접 드러남
- 구매 직후 정답 공개 제거
- 구매 후 유료 검사 3종 중 최대 2회 선택
- 전문 감정은 선택 가능한 최종 확인 수단
- 전문 구매자 견적은 처음부터 가격이 보이지 않음
- 전문 견적 요청 2회 제한, 고물상만 즉시가 공개
- 결과 화면에서 왜 벌거나 잃었는지 복기
- 기존 숨은 실제 가치와 감정 불변성 유지
- 로컬 저장에 장터 상태, 조사, 가설, 협상, 검사, 견적 상태까지 포함

## 구조

- `data/content.gd`: 아이템 / 판매자 / 단서 / 구매자 / 조사 비용·제한 데이터
- `scripts/game_logic.gd`: 매물 생성, 조사, 가설 평가, 가격 협상, 검사, 감정, 구매자 제안
- `scripts/main.gd`: 플레이 상태 머신, UI 연결, 장터 공유 자원, 저장
- `scenes/main.tscn`: 390×844 모바일 placeholder UI
- `tests/core_smoke_test.gd`: v0.2.1 코어 상호작용 자동 테스트

## 실행

Godot 4.x에서 저장소 루트를 열고 실행합니다.

- 메인 씬: `res://scenes/main.tscn`
- 기준 해상도: 390×844
- PC Godot / iPhone Xogot 터치 입력 설정 유지
- 실제 아트 제작 없이 Control / Label / Button / Slider / OptionButton만 사용

## 의도적으로 하지 않은 것

로그인, 서버, 실제 사용자 거래, 멀티플레이, 생성형 AI NPC 대화, 월드맵, 퀘스트, 과금/광고, 대규모 에셋, 픽셀아트, 캐릭터 그림, 복잡한 애니메이션은 포함하지 않습니다.

자세한 흐름은 `docs/V0_2_1_CORE_INTERACTION.md`를 참고하세요.
