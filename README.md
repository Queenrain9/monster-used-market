# 괴물 중고마켓 MVP v0.1

모바일 세로형 Godot 4.x 프로토타입입니다.

## 현재 목표

첫 번째 플레이 가능한 루프만 구현합니다.

1. 매물 발견
2. 괴물 판매자와 흥정
3. 구매
4. 감정
5. 되팔기
6. 손익 확인
7. 새 매물 갱신

## 실행

Godot 4.x에서 저장소 루트를 프로젝트로 열고 실행합니다.

- 메인 씬: `res://scenes/main.tscn`
- 기준 해상도: 390 × 844 (세로)
- iPhone/Xogot 터치 테스트를 고려해 포인팅 터치 에뮬레이션 설정을 포함합니다.

## MVP 원칙

- 서버 없음
- 로그인 없음
- 실시간 유저 거래 없음
- 생성형 AI 채팅 없음
- 이미지 에셋 없이도 게임 루프가 재미있는지 먼저 검증
- 상태 데이터와 UI를 단순하게 유지해 이후 아트/콘텐츠 확장이 쉽게 설계

## 다음 단계

코어 루프가 충분히 재미있는지 확인한 뒤 괴물 상인, 아이템 아이콘, 감정 연출, 사운드, 진행/도감 시스템을 추가합니다.
