# 괴물 중고마켓 MVP v0.2.8 — Resale Fidelity Pass

이번 버전은 기능 추가가 아니라 **구조 목업과 실제 Godot 홈 화면의 비율/밀도/정보 위계를 맞추는 패스**입니다.

## 이번 패스에서 바뀐 홈

- 야시장 배경/장식 강조를 잠시 제거하고 중립적인 와이어프레임 톤으로 전환
- 검색창 → 상단 탭 → 한 줄 카테고리 → 시장 상태 → 매물 피드 → 하단 네비 순서로 재배치
- 카테고리 7개를 세로로 찌그러뜨리지 않고 한 줄로 배치
- 큰 시장 배너를 작은 상태 바 형태로 축소
- 매물 카드 높이를 약 96px로 줄이고 썸네일 / 이름 / 가격 / 지역·시간 / 태그 / 판매자를 분리
- 긴 텍스트는 카드 높이를 늘리지 않고 잘라서 피드 밀도 유지
- 특별 매물은 동일 카드 구조에서 테두리만 한 단계 강조
- 기존 검색/필터/조사/흥정/보유품/감정/재판매/저장 로직 유지

## 의도

현재 단계의 성공 기준은 “예쁜가”가 아니라:

1. 구조 목업과 화면 실루엣이 가까운가
2. 390×844 안에서 정보가 찌그러지지 않는가
3. 한눈에 매물 여러 개를 비교할 수 있는가
4. 이후 실제 아트를 교체해도 구조를 다시 뜯지 않아도 되는가

상세/감정소는 홈 구조를 실제 플레이로 확인한 뒤 같은 방식으로 다음 패스에서 맞춥니다.


## v0.2.6 상세 화면 패스

- 상세 화면에서는 공통 헤더/하단 네비를 숨기고 전용 상단바를 사용
- 대표 이미지와 요약 정보를 2열 구조로 배치
- 이름/가격/태그/판매자를 분리
- 상세 정보와 판매자 정보를 독립 섹션으로 구분
- 주요 행동 3개와 추가 조사 3개를 실제 가로 버튼으로 고정해 세로 막대 레이아웃 오류 제거
- 시장 시세 참고와 거래 계획을 별도 섹션으로 유지
- 조사/거래 계획/흥정 로직은 변경하지 않음


## v0.2.7 상세 압축 + 감정소 패스

- 상세의 조사 액션을 `외형 / 각인 / 작동 상태 / 출처 / 시세` 한 섹션으로 통합
- 의미 없는 `감정은 구매 후` 비활성 버튼 제거
- 확인한 정보와 시세 참고를 거래 계획 직전에 배치해 판단 흐름을 단축
- 감정소는 공통 헤더/하단 네비를 숨기고 전용 상단바 사용
- 감정 전: 아이템 요약 → 현재 정보 → 추가 검사 3종 → 전문 감정 / 판매 선택
- 전문 감정 후: 아이템 요약 → 감정 결과표 → 감정사 코멘트 → 보관 / 재판매
- 검사 비용, 검사 기회, 전문 감정 비용, 기존 숨은 상태 공개 로직은 변경하지 않음


## v0.2.8 재판매 화면 패스

- 재판매 화면도 상세/감정소와 같은 전용 상단바 구조로 통일
- 판매할 아이템 이미지, 매입가, 감정 상태/예상 시세를 상단 요약 카드에 표시
- 전문 견적 남은 횟수를 별도 상태 영역으로 분리
- 전문 판매처 3곳을 각각 `이름 / 성향 / 견적 상태 / 견적 이유 / 선택 버튼` 카드로 구성
- 전문 판매처 가격은 견적 요청 전까지 숨김
- 고물상은 별도 `즉시 판매` 카드로 분리하고 즉시 매입가를 항상 공개
- 선택한 판매처의 상태를 하단 액션 패널에서 다시 확인한 뒤 견적 요청 또는 판매
- 전문 견적 2회 제한, 구매자 선호 태그, 고물상 즉시가, 판매/복기 로직은 변경하지 않음
