# 괴물 중고마켓 MVP v0.2

모바일 세로형 Godot 4.x 프로토타입입니다.

v0.2의 목표는 기능 수를 늘리는 것이 아니라 **괴물 중고거래에서 단서를 읽고, 판매자를 파악하고, 흥정하고, 감정 결과를 확인한 뒤 가장 좋은 구매자에게 되파는 판단의 재미**를 강화하는 것입니다.

## 현재 플레이 루프

1. 50,000G로 시작
2. 매물 3개 비교
3. 가격 / 판매자 성격 / 공개 단서 확인
4. 매물 하나 선택
5. 판매자와 최대 3회 흥정
6. 현재가 구매 또는 거래 포기
7. 구매 전 단서를 다시 확인하고 감정
8. 진품 여부 / 희귀도 / 상태 / 실제 가치 공개
9. 단서가 실제 결과와 어떻게 연결됐는지 피드백 확인
10. 서로 다른 성향의 구매자 3명 제안 비교
11. 판매 대상 선택
12. 손익 및 누적 기록 확인
13. 다음 매물 반복

## v0.2 핵심 변경

- 아이템 12종
- 판매자 성격 5종
- 판매자 캐릭터 8명
- 구매자 유형 5종
- 단서 30개 이상
- 같은 아이템 이름이라도 진품 / 모조품 / 결함품, 상태, 희귀도가 매번 달라짐
- 숨은 상태를 먼저 만든 뒤 단서를 생성하므로 감정 결과와 단서가 논리적으로 연결됨
- 판매자 성격이 희망가, 주장 신뢰도, 흥정 반응, 인내도에 실제 영향
- 흥정은 빠른 거래 제안 / 상태 지적 / 작은 추가 할인으로 최대 3회 진행
- 감정은 결과를 새로 랜덤 생성하지 않고 이미 정해진 숨은 상태를 공개
- 구매자별 선호 태그와 희귀도 반응에 따라 제안가 차등
- 안정형 / 애매형 / 고위험형 / 대박 후보 / 함정형 매물이 섞여 경제 결과가 달라짐
- 오늘 거래 횟수 / 누적 거래 / 최고 단일 수익 / 최고 손실 / 희귀 발견 기록
- 거래 도중 앱을 닫아도 흥정 / 구매 / 감정 / 판매 단계가 로컬 저장으로 이어짐

## 구조

- `data/content.gd`: Item / Seller / Clue / Buyer 콘텐츠 데이터
- `scripts/game_logic.gd`: 매물 생성, 숨은 가치, 단서, 흥정, 감정, 구매자 제안 로직
- `scripts/main.gd`: 화면 전환, 입력, 로컬 저장, UI 연결
- `scenes/main.tscn`: 390×844 세로 모바일 UI

새 아이템이나 NPC를 추가할 때 화면 코드를 직접 수정하지 않고 `data/content.gd` 중심으로 확장할 수 있도록 분리했습니다.

## 실행

Godot 4.x에서 저장소 루트를 프로젝트로 열고 실행합니다.

- 메인 씬: `res://scenes/main.tscn`
- 기준 해상도: 390 × 844
- PC Godot / iPhone Xogot 터치 테스트를 위해 터치-마우스 에뮬레이션 설정 유지
- 별도 이미지 에셋 없이 텍스트와 기본 UI만 사용

## 이번 버전에서 하지 않은 것

로그인, 서버, 실제 사용자 거래, 멀티플레이, 생성형 AI NPC 대화, 월드맵, 복잡한 퀘스트, 과금/광고, 대규모 이미지 에셋, 픽셀아트, 캐릭터 일러스트, 장식용 애니메이션은 포함하지 않습니다.

자세한 설계와 테스트 체크리스트는 `docs/V0_2_DESIGN.md`를 참고하세요.
