# 괴물 중고마켓 MVP v0.2.4 — Structure UI Integration

첨부한 구조 목업을 기준으로 **홈 피드 / 아이템 상세 / 감정 결과**의 정보 위계와 실제 상호작용을 구현한 Godot 모바일 프로토타입입니다.

## 이번 버전

- 홈: 실제 검색, 추천/흥정 가능/확인한 매물/카테고리 탭, 카테고리 필터, 빈 결과 상태
- 상세: 대표 이미지, 썸네일 슬롯, 이미지 확대 팝업, 아이템/판매자/설명/상세 정보, 판매자 문의, 시장 시세, 기존 조사·거래 계획·흥정
- 감정 결과: 전문 감정 후 별도 결과 상태, 진품 여부/마력 잔량/저주 강도/희귀도/예상 시세, 감정사 코멘트
- 재판매 준비는 확인 팝업 후 기존 판매처 선택으로 이동
- 기존 숨은 가치, 조사 자원, 단서 기반 흥정, 보유품, 검사 비용, 전문 판매처 3곳+고물상, 견적 2회 제한, 저장 유지
- 390×844 세로 화면, 가로 스크롤 금지

검색/필터는 현재 장터의 실제 데이터만 사용합니다. 서버, 위치 기반 근처 기능, 자유 채팅, 사용자 등록, 과금 기능은 추가하지 않았습니다.

## 실행

Godot 4.5.1 이상에서 저장소 루트를 열고 실행합니다.

- 메인 씬: `res://scenes/main.tscn`
- 기준 해상도: 390×844
- PC 마우스 / iPhone Xogot 터치 대응

설계: `docs/V0_2_4_STRUCTURE_UI.md`
