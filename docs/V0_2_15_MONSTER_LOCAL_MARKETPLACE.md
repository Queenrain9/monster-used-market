# v0.2.15 — Monster Local Marketplace Fantasy

## 핵심 문제

기존 게임은 거래 시스템은 있었지만 화면 언어가 여전히 게임 시스템 중심이었다.

- 홈 카드의 한 줄은 판매자 글이 아니라 단서였다.
- 판매자는 이름만 있고 동네와 생활 맥락이 약했다.
- 상세는 게시글보다 감정 데이터 시트에 가까웠다.
- 흥정은 채팅/가격제안보다 시스템 협상처럼 보였다.

## 해결 방향

핵심 게임 규칙은 유지한다.

`매물 선택 → 조사 → 매입 상한 → 가격 제안 → 직거래 → 감정/판매`

대신 플레이어가 이 구조를 **로컬 중고거래**로 느끼도록 public presentation을 변경한다.

## Seller-written listing stories

각 아이템은 3개의 `market_stories`를 가진다.

예:

- 저주받은 손거울: “오래된 집에서 가져온 손거울이에요. 밤에는 천을 덮어두고 있었습니다.”
- 망자의 뼈피리: “소리는 나는데 밤에 불면 이웃들이 싫어해서 정리해요.”
- 미믹의 황동열쇠: “열리는 문은 못 찾았고 서랍에만 굴러다녀서 내놓습니다.”

이 문장은 hidden state에서 생성하지 않는다.

즉 사연 자체가 진품/모조품/함정의 정답 표식이 되지 않는다.

## Seller locality

판매자마다 로컬 생활권을 가진다.

```
seller
├ neighborhood
├ meetup
└ profile
```

거래 화면은 이 정보를 끝까지 유지한다.

## Detail hierarchy

1. 물건 이미지 / 가격
2. 판매자 / 동네 / 업로드 시각
3. 판매글
4. 거래 정보 / meetup
5. 괴물 판매자 프로필
6. 물건 추가 확인
7. 가격 제안 준비

따라서 먼저 “누가 무엇을 왜 파는지”를 보고, 그 다음 게임적 분석에 들어간다.

## Negotiation

수락/카운터/거절 공식은 변경하지 않는다.

화면 언어만 지역 중고거래의 가격 제안으로 번역한다.

- 판매자가 올린 가격
- 내 최대 매입가
- 가격 제안 보내기
- 판매자 답장
- 직거래 장소
- 바로 거래

## Legacy saves

기존 저장에 marketplace metadata가 없어도:

- seller_id → 최신 seller locality
- item_id → seller story fallback

을 사용한다.

따라서 저장 초기화 없이 새 표현을 볼 수 있다.
