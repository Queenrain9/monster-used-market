# v0.2.3 — Home Feed Art Integration

사용자가 제공한 `괴물마켓.zip`의 그림으로 홈 피드를 발전시킨 시각 업데이트다. 첨부 방향 메모의 야시장 분위기, 썸네일 카드, 판매자 초상화, 밝은 카드와 어두운 배경의 대비를 적용한다. 실제 기능은 기존 홈 / 보유품 / 거래 기록과 상세·조사·흥정·감정·판매 흐름이다.

## 데이터와 이미지의 경계

- `data/art_catalog.gd`: 아이템 12종, 판매자 8명, 시장/브랜드/감정사/공통 이미지의 경로와 공개 표시 이름.
- `scripts/art_catalog.gd`: 경로 조회, 이미지 캐시, 누락 시 공통 이미지, 공개 이름 조회.
- `assets/art/`: ZIP 원본 24개를 그대로 복사했다. JPG 확장자였지만 실제 PNG였던 4개는 확장자만 바로잡았다. 이미지의 내용은 편집하지 않았다. 원본 파일명은 `assets/art/SOURCES.json`에 기록했다.
- `scripts/market_theme.gd`: 기본 Godot Control 스타일. 새 그림을 코드로 그리지 않는다.

ZIP에 맞춘 표시 이름은 **표현 계층에서만** 적용한다. 예를 들어 기존 `moon_ring`은 ‘빛나는 낡은 반지’, `soul_lantern`은 ‘저주받은 램프’로 표시한다. 기존 ID, 원래 저장 이름, 분류/태그, 생성 확률, 가격 분포, 판매자 성향, 단서, 비용과 견적 규칙은 바꾸지 않는다. 따라서 기존 게임 데이터의 분류는 밸런스용으로 유지되며 이번 업데이트에 새 물건 유형이나 새 수익 공식은 없다. 직접 수정된 이름은 덮어쓰지 않는다. 과거 거래 결과의 저장된 문장은 당시 이름을 유지한다.

홈·상세·보유품·흥정·감정·재판매·새 거래 결과는 같은 표시 이름을 사용한다. 이름 스킨을 되돌리려면 manifest의 `name`을 `legacy_name`과 같게 바꾸면 된다. 실제 구매한 물건이나 진행 상태는 새로 생성하지 않는다. 프로젝트 이름과 저장 경로도 v0.2.3 그대로 유지한다.

그림 선택에는 공개 아이템/판매자 ID만 사용한다. 진품/모조품/결함품, 희귀도, 실제 가치, archetype에 따라 이미지나 효과를 바꾸지 않는다. 상세에서 ‘대표 이미지입니다. 실제 상태와 진위는 조사로 확인하세요.’를 표시한다. 특별 매물의 선정 규칙도 그대로이며 보라색 테두리와 문구만 구분한다.

## 교체 방법

1. 같은 물건의 그림만 교체한다면 `assets/art/items/` 또는 `sellers/`의 해당 파일을 같은 이름으로 교체한다. Godot에서 자동으로 다시 가져온다.
2. 경로나 파일 형식을 바꾸려면 `data/art_catalog.gd`의 해당 `texture` 한 곳을 수정한다. 표시 이름은 같은 항목의 `name`에서 바꾼다. ID는 저장 호환을 위해 유지한다.
3. 아이템은 정사각형 구도를 권장한다. `TextureRect`가 원본 크기로 레이아웃을 밀지 않고 비율을 유지한다. 아이템 최대 512px, 판매자 256px, 시장 768px로 가져오며 원본 파일은 보존한다. `.import` 파일에 설정을 보관한다.
4. 없는 ID나 없는 파일은 공통 이미지로 대체한다. 공통 이미지까지 없으면 그림 없이 텍스트와 거래 기능이 남는다. 이미지 교체 후 Godot를 다시 실행해 캐시를 갱신한다.
5. 배포 내보내기는 **프로젝트의 모든 리소스**를 포함한다. 이미지는 manifest의 문자열 경로로 읽기 때문에 ‘선택한 씬만 내보내기’를 쓰면 `assets/art/`도 반드시 선택한다.

## 유지하는 경험

장터당 공유 조사 4회, A → 홈 → B → 홈 → A 상태 보존, 다음 장터의 조사 소진/실제 구매 조건, 예상 재판매가·매입 한도, 단서 기반 흥정, 유료 추가 검사·선택 감정, 전문 견적 2회, 고물상 판매, 최근 거래 복기를 그대로 유지한다. 새로운 검색/필터/알림/보석 재화/채팅/좋아요는 추가하지 않는다.

## 검증

- 이미지 import 후 메인 씬 부팅, 기존 core smoke와 home feed smoke.
- art smoke: 전체 아이템/판매자 연결, 실제 텍스처 로드와 크기, 알 수 없는 ID/누락 파일 대체, 이미지·표시 이름이 저장을 변경하지 않음, 숨겨진 상태에 따른 홈 정보 불변.
- 실제 390×844 Control 좌표, 긴 이름/단서/선택 팝업, 가로 스크롤 없음, 고정 하단 메뉴.
- PC 렌더링으로 홈/특별 매물/상세/기록 캡처. iPhone Xogot 기기 확인은 별도로 필요하다.
