# v0.2.4 — Structure UI Integration

## 구현 기준

구조 목업 3장을 다음 역할로 사용한다.

1. 홈 피드 구조
2. 아이템 상세 구조
3. 감정 결과 구조

최종 일러스트를 복제하지 않고 현재 프로젝트의 실제 데이터와 버튼 흐름을 배치한다.

## 홈

- 상단 재화/보유품은 기존 헤더 재사용
- 검색은 아이템 이름, 판매자 이름, 카테고리를 실제 필터링
- 탭: 추천 / 흥정 가능 / 확인한 매물 / 카테고리
- 카테고리: 전체 / 장신구 / 재료 / 유물 / 마도구 / 잡화 / 기타
- 결과가 없으면 실제 빈 상태 표시
- 숨은 진위/가치/희귀도는 노출하지 않음

## 상세

- 대표 이미지와 향후 다중 이미지용 4개 썸네일 슬롯
- 현재 실제 이미지가 1장이므로 첫 슬롯만 활성
- 이미지 확대 팝업
- 아이템 요약 / 공개 태그 / 판매자 / 설명 / 상세 공개 정보 / 판매자 정보
- 판매자 문의와 시세 확인은 기존 조사 자원에 연결
- 상태 확인 3종, 발견 단서, 거래 계획과 흥정 유지

## 감정 결과

전문 감정 뒤 같은 감정소 화면을 결과 상태로 전환한다.

- 진품 여부
- 마력 잔량: 기존 태그+희귀도의 표시용 등급
- 저주 강도: 저주 태그+희귀도의 표시용 등급
- 희귀도
- 예상 시세 범위: 실제 가치를 재추첨하지 않고 기존 값을 기준으로 표시
- 감정사 코멘트
- 보관 / 재판매 준비

재판매 준비는 확인 팝업 뒤 기존 3개 전문 판매처+고물상 화면으로 이동한다.

## 범위 밖

자유 채팅, 위치 기반 근처 매물, 실제 사용자 판매 등록, 좋아요/관심 수, 과금 재화, 신규 핵심 게임 규칙, 최종 아트 제작.
