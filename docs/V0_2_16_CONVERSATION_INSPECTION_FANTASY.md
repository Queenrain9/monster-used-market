# v0.2.16 — Conversation & Inspection Fantasy

## 목적

기존 조사 시스템의 기능은 충분했지만 버튼을 누르는 방식이 분석 도구처럼 느껴졌다.

이번 패스는 같은 게임 규칙을 **괴물과 실제 중고거래를 하는 행동**으로 번역한다.

## 원칙

- 자유채팅 시스템을 만들지 않는다.
- 조사 수학과 숨은 상태는 바꾸지 않는다.
- 기존 investigation action ID를 유지한다.
- 플레이어에게 보이는 문구와 결과 표현만 더 생활감 있게 만든다.

## Action Presentation

`exterior`
- 물건의 특정 부위 사진을 더 본다.

`mark`
- 판매자에게 해당 부위의 추가 사진을 요청한다.

`function`
- 직거래 전 직접 작동/무게/반응을 확인한다.

`origin`
- 판매자에게 어디서 얻었는지 질문한다.

`market`
- 중고장터와 상점 기록에서 비슷한 매물을 검색한다.

## Last Inquiry

각 매물은 선택적으로 `last_inquiry`를 가진다.

```
{
  title,
  kind,
  text
}
```

상세 화면은 가장 최근 상호작용을 별도 패널로 보여준다.

모든 발견 사실은 기존 `discovered_clues`에도 계속 저장된다.

## Seller Inference

판매자 성격명 대신 observable signals를 사용한다.

- 최근 활동
- 거래 속도 선호
- 실제 메시지
- 프로필 소개

사후 거래 기록에서만 실제 성향을 복기한다.

## 성공 기준

플레이어가 조사 버튼을 보고:

“어떤 분석 메뉴를 누르지?”

보다

“판매자한테 뭘 더 물어보지?”

를 먼저 생각해야 한다.
