# NEG-02 — 제안 작성

## 목적

플레이어가 **근거와 가격을 하나의 제안으로 만든다.**

## 근거 선택 구조

드롭다운 안에서 발견한 단서를 단순 문장 목록으로 보여주지 말고 의미를 빠르게 읽을 수 있게 한다.

예:

```
흥정 근거

○ 근거 없이 가격만 제안
○ [부정적] 한쪽이 조금 휘어 있다
○ [부정적] 마법 각인이 안쪽까지 이어지지 않는다
○ [애매] 판매자가 출처 질문에 잠깐 망설였다
```

현재 데이터와 로직은 그대로 사용한다.

- `negotiation_evidence_options(listing)`
- `clue_index`
- `kind`
- `text`

## 가격 조정

### 기본

슬라이더 범위:

- 최소 = 현재 판매자 가격의 50%
- 최대 = 현재 판매자 가격
- step = 50G

현재 구현 유지.

### 프리셋

- -5%
- -10%
- -20%

프리셋은 **판매자 현재가 기준**.

## 중요 상태

### 제안가 <= 내 최대 매입가

정상 상태.

### 제안가 > 내 최대 매입가

경고 상태.

직접 구매 가능성은 유지하지만 색/문구로 위험을 알려준다.

### 근거 없음

허용.

전문가 판매자에게는 불리할 수 있다는 기존 로직을 그대로 사용한다.

## 제출 결과

`SubmitOfferButton` 클릭 시 UI에서 자체적으로 결과를 계산하지 않는다.

반드시:

`engine.negotiate_offer(listing, state, offer_price, clue_index)`

결과를 사용한다.
