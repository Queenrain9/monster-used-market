# NEG-03 — 판매자 반응 / 카운터

## 목적

버튼을 눌렀더니 숫자가 조용히 바뀌는 것이 아니라, **내 제안이 판매자 상태에 영향을 줬다는 것을 읽게 한다.**

## 카운터 예시

```
┌──────────────────────────────┐
│ 판매자 요구가                │
│ 20,943G  →  19,300G          │
│                              │
│ 내 직전 제안        18,200G   │
│ 사용 근거  “각인이 끊겨 있다” │
├──────────────────────────────┤
│ 판매자 반응                  │
│ “그건 나도 알아. 그래도       │
│  18,200은 너무 낮아.          │
│  19,300이면 넘기지.”          │
├──────────────────────────────┤
│ 협상 1 / 3       인내도 ●●○ │
├──────────────────────────────┤
│ 다음 제안가        18,850G    │
│ ───────●──────────           │
│ [-5%] [-10%] [-20%]         │
│ [다시 제안]                  │
├──────────────────────────────┤
│ [19,300G에 구매] [거래 보류] │
└──────────────────────────────┘
```

## 반드시 보일 변화

- 이전 가격
- 새 current_price
- 직전 offer
- 직전 evidence
- rounds
- patience
- seller speech

## 거절

카운터 없이 거절된 경우:

```
판매자 가격 20,943G · 유지
내 제안 11,000G · 거절

인내도 ●○○
“그 가격이면 그냥 안 팔지.”
```

## 반복 근거

이미 사용한 동일 단서를 다시 선택할 수는 있다.

기존 로직처럼 효과가 크게 감소한다.

UI는 가능하면:

`이미 사용한 근거 · 효과 감소`

상태를 표시한다.

새 규칙을 만들지는 않는다.
