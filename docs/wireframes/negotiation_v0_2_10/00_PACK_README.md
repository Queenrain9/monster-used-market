# 괴물 중고마켓 — Negotiation Interaction Wireframe Pack v0.2.10

## 목적

이 Pack은 `Concept → Interaction Wireframe Pack` 워크플로우로 만든 **개발용 흥정 화면 명세**다.

이미지 콘셉트나 최종 UI 아트가 아니라 다음 구현을 위한 자료다.

- 화면 구조
- 정보 위계
- 상태 변화
- 입력 규칙
- 버튼 활성/비활성
- 기존 게임 데이터 연결
- Godot 노드 매핑
- 회귀 테스트 기준

## 이번 Pack의 핵심

현재 흥정 로직은 이미 충분히 존재한다.

- 플레이어 거래 계획
- 예상 재판매가
- 최대 매입가
- 판매자 현재 가격
- 최대 3회 협상
- 판매자 인내도
- 발견 단서 선택
- 직접 제안가 결정
- 판매자 성격별 수락 / 카운터 / 거절
- 현재가 즉시 구매

따라서 v0.2.10은 **새 흥정 시스템을 추가하지 않는다.**

목표는 이 시스템을 플레이어가 한눈에 이해하고 조작할 수 있는 화면으로 번역하는 것이다.

## 화면 ID

| ID | 상태 | 핵심 질문 |
|---|---|---|
| NEG-01 | 협상 진입 | 지금 이 물건을 얼마에 사려고 했지? |
| NEG-02 | 제안 작성 | 어떤 근거로 얼마를 부를까? |
| NEG-03 | 판매자 반응 | 판매자가 어떻게 반응했고 가격이 어떻게 변했지? |
| NEG-04 | 협상 종료 | 지금 살까, 멈출까? |

## 최우선 UX 원칙

플레이어가 읽어야 할 중심 문장은 판매자 대사가 아니라:

**현재 판매자 가격 → 내 매입 상한 → 내가 고른 근거 → 내 제안가 → 판매자의 새 가격**

이어야 한다.

채팅 화면처럼 보여도 핵심 조작은 반드시 **가격 + 근거**다.
