# NEG-01 — 협상 진입

## 목적

상세 화면에서 세운 거래 계획을 협상 화면으로 가져와 **내 기준을 잊지 않게 하는 상태**.

## Wireframe

```
┌──────────────────────────────┐
│ ←  가격 협상        52,232 G │
├──────────────────────────────┤
│ [아이템 썸네일]  빛나는 낡은 반지 │
│                 판매자: 눈물냥이  │
│                 급한 판매자       │
├──────────────────────────────┤
│ 판매자 요구가        20,943 G │
│ 내 최대 매입가       17,800 G │
│ 예상 재판매가   15,000~30,000G │
├──────────────────────────────┤
│ 협상 상태                     │
│ 0 / 3회       인내도 ●●○      │
├──────────────────────────────┤
│ 흥정에 쓸 근거                │
│ [ 발견 단서 선택 ▼ ]          │
├──────────────────────────────┤
│ 내 제안가          18,850 G   │
│ ────────●─────────            │
│ [-5%]      [-10%]      [-20%]│
│                              │
│ [ 이 가격과 근거로 제안 ]     │
├──────────────────────────────┤
│ 판매자 반응                    │
│ “가격을 불러봐. 이유가 있으면 │
│  들어보지.”                    │
├──────────────────────────────┤
│ [현재가에 구매] [거래 보류]   │
└──────────────────────────────┘
```

## 정보 우선순위

1. 판매자 요구가
2. 내 최대 매입가
3. 내 제안가
4. 선택한 근거
5. 협상 횟수 / 인내도
6. 판매자 반응

## 인터랙션

- 근거 선택: `EvidenceOption`
- 가격 직접 조정: `OfferSlider`
- 빠른 조정: -5 / -10 / -20%
- 제출: `SubmitOfferButton`
- 현재가 구매: `BuyCurrentButton`
- 보류: `DealBackButton`

## 상태 표시

제안가가 최대 매입가보다 높아지면:

`⚠ 내 매입 상한보다 1,050G 높음`

처럼 슬라이더 바로 아래에서 경고.

구매를 막지는 않는다.
