# 08. Acceptance Tests

## 구조

- [ ] 390×844에서 가로 스크롤 없음
- [ ] 첫 화면에서 판매자 현재가, 최대 매입가, 제안가가 동시에 보임
- [ ] 판매자 반응 영역이 화면 안에서 별도 영역으로 구분됨
- [ ] 주요 CTA가 화면 폭 밖으로 잘리지 않음
- [ ] 긴 단서 문장 때문에 화면 폭이 늘어나지 않음

## 상호작용

- [ ] 상세에서 저장한 예상 재판매가가 협상 화면에 표시됨
- [ ] 상세에서 저장한 최대 매입가가 협상 화면에 표시됨
- [ ] 발견한 단서만 근거 목록에 표시됨
- [ ] -5/-10/-20 프리셋이 current_price 기준으로 동작
- [ ] 슬라이더 직접 조정 가능
- [ ] 최대 매입가 초과 시 경고 표시
- [ ] 근거 없이 제안 가능
- [ ] 제안 시 엔진의 카운터/거절/수락 결과를 그대로 사용

## 상태 변화

- [ ] 카운터 후 이전 가격과 새 가격의 변화가 읽힘
- [ ] rounds가 증가함
- [ ] patience 변화가 반영됨
- [ ] 반복 근거 사용 시 게임 로직이 유지됨
- [ ] closed 상태에서 새 제안 불가
- [ ] closed 상태에서도 현재가 구매 / 보류 가능
- [ ] accepted 상태는 불필요한 중간 화면 없이 구매 완료로 연결

## 회귀

- [ ] 구매 시 gold 차감
- [ ] 구매한 아이템이 inventory에 들어감
- [ ] 거래 보류 시 매물이 사라지지 않음
- [ ] 기존 조사 데이터 유지
- [ ] 저장/재실행 후 정상 복원
- [ ] 홈/상세/감정/재판매 기존 플로우 손상 없음

## 성공 기준

플레이어가 화면에서 가장 먼저 생각해야 할 것:

- 이 판매자의 현재 가격이 얼마지?
- 내가 정한 상한은 얼마였지?
- 어떤 단서를 근거로 쓸까?
- 얼마를 제안할까?
- 판매자가 카운터했는데 받아들일까, 다시 제안할까?

**“어떤 버튼을 누르면 다음 화면이지?”가 되면 실패.**
