# NEG-04 — 종료 상태

## A. 제안 수락

엔진이 `accepted = true`를 반환하면 별도 축하 화면을 만들지 않는다.

짧은 수락 피드백 후 기존 구매 완료 흐름으로 이동.

```
판매자가 제안을 받아들였습니다.
18,200G에 구매
→ 보유품
```

목표: 불필요한 `다음` 화면 방지.

## B. 협상 기회 종료

`closed = true`

```
협상 종료

판매자 최종 가격   19,300G
내 최대 매입가     17,800G

판매자:
“흥정은 끝났어. 살지 말지만 정해.”

[19,300G에 구매]
[거래 보류]
```

새 제안 컨트롤은 비활성.

## C. 골드 부족

현재 가격 > gold

현재가 구매 버튼 비활성.

문구:

`보유 골드보다 4,200G 부족`

## D. 거래 보류

시장으로 돌아감.

- 구매 안 함
- 매물 삭제 안 함
- 기존 조사 정보 유지
- 협상 상태 유지 여부는 현재 저장 정책을 따른다

v0.2.10에서 별도 규칙 변경 금지.
