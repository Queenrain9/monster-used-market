# MVP v0.1 Scope

## 목표

앱스토어용 완성본을 바로 만들기 전에, **매물 → 흥정 → 구매 → 감정 → 판매 → 손익 → 새 매물** 루프가 실제 모바일 화면에서 재미있는지 검증한다.

## 구현됨

- 시작 자금 50,000G
- 매 라운드 랜덤 매물 3개
- 아이템 8종
- 괴물 판매자별 완고함 수치
- 정가 / 10% 할인 / 25% 할인 흥정
- 흥정 거절과 판매자 인내도
- 구매 후 감정
- 아이템별 숨겨진 실제 가치 범위
- 구매자의 최종 제안가
- 손익 계산
- 누적 거래 횟수
- 로컬 세이브
- 테스트 데이터 초기화
- 세로형 390×844 기준 UI
- 터치 입력 설정

## 아직 하지 않음

## v0.1 플레이 테스트 질문

1. 감정 버튼을 누르기 전 결과가 궁금한가?
2. 흥정할 때 10%와 25% 사이에서 고민하게 되는가?
3. 손해를 봤을 때 다음 거래를 한 번 더 하고 싶은가?
4. 대박 거래가 나왔을 때 만족감이 있는가?
5. 10분 플레이 후 반복감이 너무 강한가?

이 다섯 질문에 답한 다음 v0.2의 규칙을 결정한다.
