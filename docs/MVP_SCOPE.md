# MVP v0.2 Scope

## 목표

v0.1의 **매물 → 흥정 → 구매 → 감정 → 판매 → 손익 → 새 매물** 루프는 유지하면서, 결과 확인형 랜덤 게임이 아니라 **관찰 + 추론 + 위험 감수 + 흥정 + 판매 판단** 게임으로 발전시킨다.

## 구현 범위

- 시작 자금 50,000G
- 매 라운드 매물 3개
- 아이템 12종
- 판매자 성격 5종
- 판매자 캐릭터 8명
- 구매자 유형 5종
- 단서 30개 이상
- 진품 / 모조품 / 결함품
- 희귀도 / 보존 상태
- 실제 가치 / 희망 가격 분리
- 긍정적 / 부정적 / 애매한 / 판매자 주장 단서
- 판매자 성격에 따른 희망가·주장 신뢰도·흥정 난이도
- 최대 3회 흥정
- 단서 기반 상태 지적 흥정
- 감정 결과와 사전 단서의 연결 피드백
- 구매자 3명 제안 비교
- 구매자 선호 속성에 따른 제안가 차등
- 안정형 / 애매형 / 고위험형 / 대박 후보 / 함정형 매물 혼합
- 누적 자산
- 오늘 거래 횟수
- 최고 단일 거래 수익
- 최고 손실
- 발견한 희귀 아이템 기록
- 단계별 로컬 저장
- 390×844 세로 UI
- PC / 터치 입력 유지

## 구조 원칙

`Item / Seller / Listing / Clue / Buyer` 데이터는 `data/content.gd`에 모으고, 실제 매물 생성과 거래 규칙은 `scripts/game_logic.gd`에 둔다. `scripts/main.gd`는 화면과 저장 흐름을 담당한다.
