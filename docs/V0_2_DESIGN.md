# 괴물 중고마켓 v0.2 시스템 설계

## 1. 숨은 가치 생성 순서

매물 생성 시 아래 정보가 먼저 결정된다.

1. 아이템 종류
2. 진품 / 모조품 / 결함품
3. 보존 상태
4. 희귀도
5. 실제 가치
6. 판매자와 판매자 성격
7. 매물 위험 유형
8. 희망 가격
9. 공개 단서 / 숨은 단서

중요한 점은 **감정 버튼을 누를 때 실제 가치가 새로 랜덤 생성되지 않는 것**이다. 감정은 매물 생성 시 이미 결정된 정보를 공개한다.

## 2. 단서

단서는 긍정적 / 부정적 / 애매한 / 판매자 주장으로 구분된다.

대부분 실제 상태와 연결되지만 일부 흔적은 오해를 유도할 수 있다. 감정 결과 화면에서 플레이어가 봤던 단서와 실제 판정 이유를 다시 연결해 보여준다.

## 3. 판매자 성격

- 급한 판매자: 할인 수용도가 높고 희망가가 낮아질 가능성이 큼
- 욕심 많은 판매자: 할인 수용도가 낮고 가격을 높게 부르는 경향
- 허풍쟁이: 판매자 주장의 신뢰도가 낮음
- 순진한 판매자: 가치 지식이 낮아 대박/함정 모두 가능
- 전문가: 시세를 잘 알고 설명 신뢰도가 높으며 큰 차익은 어려움

성격은 화면에서 공개된다.

## 4. 흥정

플레이어는 최대 3회의 흥정 행동을 할 수 있다.

- 지금 바로 살겠다는 강한 할인 제안
- 공개된 상태 단서를 근거로 가격 지적
- 작은 추가 할인 요청
- 현재가 구매
- 거래 포기

판매자 성격, 공개된 부정적 단서, 현재 기분, 남은 인내도가 결과에 영향을 준다.

## 5. 감정

감정 결과는 다음을 공개한다.

- 진품 여부
- 희귀도
- 상태
- 실제 가치
- 특징
- 구매 전 단서가 결과와 어떻게 연결됐는지

## 6. 구매자

매 감정 후 전문 구매자 2명 + 고물상 1명이 등장한다.

- 수집가: 희귀도와 수집/고대 속성 선호
- 마법사: 마법/영혼 속성 선호
- 연금술사: 재료/연금 속성 선호
- 골동품상: 고대/저주/기계 속성 선호
- 고물상: 거의 모든 물건을 사지만 낮은 가격

## 7. 경제 위험

매물은 내부적으로 다음 위험 유형 중 하나를 가진다.

- 안정형
- 애매형
- 고위험형
- 대박 후보
- 함정형

이 값은 플레이어에게 직접 표시하지 않는다. 가격과 단서, 판매자 성격을 통해 추론하게 한다.

## 8. 저장

로컬 저장에는 자산과 기록뿐 아니라 현재 매물, 선택한 매물, 흥정 상태, 구매 상태, 감정 결과, 구매자 제안까지 저장한다. 구매 직후 앱을 닫아 골드만 빠지고 아이템이 사라지는 문제를 피한다.

## 테스트 체크리스트

- 50,000G 시작 확인
- 매물 3개가 서로 다른 아이템으로 생성되는지 확인
- 동일 아이템을 여러 번 만났을 때 진위/상태/희귀도가 달라지는지 확인
- 5개 판매자 성격이 화면과 흥정 결과에 반영되는지 확인
- 부정적 단서가 있을 때 상태 지적 흥정이 상대적으로 유리한지 확인
- 최대 3회 흥정 이후 추가 흥정이 막히는지 확인
- 감정 전후 실제 가치가 바뀌지 않는지 확인
- 감정에서 단서 해석이 표시되는지 확인
- 구매자 3명의 제안가와 이유가 다른지 확인
- 손익과 자산이 정확히 반영되는지 확인
- 오늘 거래/누적/최고 수익/최고 손실/희귀 발견 기록 확인
- 흥정/구매/감정/판매 단계에서 앱 재시작 후 상태 복원 확인
- 15~20회 거래에서 결과가 단조롭게 반복되지 않는지 확인
