# v0.2.3 — Home Feed Integration

v0.2.2의 게임 규칙을 유지하면서 첫 화면을 “오늘 뭐 올라왔지?” 하고 둘러보는 장터 입구로 바꾼다. 첨부 시안은 정보 구조의 참고이며 그래픽이나 가짜 기능의 명세로 취급하지 않는다.

## 홈의 정보 계층

- 고정 상단: 괴물 중고마켓, 보유 골드, 보유품 개수. 거래 통계는 거래 기록으로 이동한다.
- 시장 상태: 어둠마을 야시장, 짧은 소개, 새 매물/거래 가능 개수, “더 자세히 확인 가능 N회”. 이 기회는 세 매물이 공유한다.
- 세로 카드 3개: 이름 → 희망가 → 판매자 → 공개 성향/진행 태그 → 최초 공개 단서 1개. 카드 전체가 상세 진입 버튼이다.
- 다음 장터: 짧은 고정 버튼과 별도의 조건 안내. 남은 조사 기회를 모두 쓰거나 실제 구매한 경우에만 열린다.
- 고정 하단: 홈 / 보유품 / 거래 기록. 감정은 선택한 보유품에서 진입한다.

‘새 매물’은 현재 거래 가능하면서 아직 열어보거나 조사하지 않은 매물 수다. 완료된 매물도 다음 장터 전까지 카드로 남지만 다시 구매할 수 없다. 방문 여부는 조사 자원을 소비하지 않는다.

홈은 최초 단서의 **문장만** 표시한다. 긍정적/부정적 분류, 판매자 주장, 추가 조사 결과, 실제 진위·상태·희귀도·가치, 거래 계획, 예상 수익, 판매처 가격은 홈에서 노출하지 않는다. 상세의 기존 정보와 조사 항목, 예상 재판매가·최대 매입가·의심 단서·가격 협상은 그대로 유지한다.

## 실제 데이터 기반 태그

| 데이터 | 홈 태그 |
| --- | --- |
| 판매자 type=urgent | 급처 |
| 그 외 discount_receptiveness≥0.6 | 흥정 여지 있음 |
| type=expert | 시세에 밝음 |
| type=greedy | 가격 고수 |
| 나머지 기존 type=bluffer | 설명 적극적 |
| 미방문 활성 매물 | 거래 가능 |
| 방문/조사한 활성 매물 | 확인한 매물 |
| 기존 listing_status=거래 중 | 거래 중 |
| 구매/판매 완료 | 해당 완료 상태 |

태그는 판매자 성향과 진행 상태를 요약한다. 신규 판매자, 인기, 관심 수처럼 근거 없는 데이터를 추가하지 않는다. 태그가 특정 할인이나 수익을 보장하지 않는다.

## 특별 매물

기존 stable / ambiguous / risky / jackpot / trap은 모두 같은 후보 자격을 갖는다. 현재 장터 첫 listing_id의 안정적인 해시로 약 세 장터 중 하나에서 최대 한 개를 표시한다. 다섯 유형 모두 동일한 ‘특별 매물’ 문구와 기본 패널 테두리를 사용한다.

이 표시는 장터를 둘러볼 때의 시각적 계층이다. jackpot을 우대하거나 trap을 배제하지 않으며, 실제 가치·진위·희귀도·결함·마진을 읽지 않는다. 게임 난수도 소비하지 않는다. 상세를 열고 돌아와도 같은 매물이 표시되고, 표시된 물건의 거래가 끝나면 다른 카드로 옮기지 않는다. 가짜 인기나 판매자의 숨은 사정을 생성하지 않는다.

## 탐색과 저장

A 상세 → 홈 → B 상세 → 홈 → A 상세에서 세 매물, 공유 조사 잔량, 발견 단서, 저장된 거래 계획과 흥정 진행이 유지된다. 홈 스크롤 위치도 복원한다. 모든 화면은 같은 기존 장터/보유품 데이터에 연결된다.

저장 스키마는 version=23이며 기존 파일명 `monster_used_market_save_v022.json`을 유지한다. 새 데이터는 방문 여부와 홈 스크롤 위치뿐이다. PC에서 프로젝트 제목 변경으로 저장 폴더가 달라졌다면 기존 v0.2.2 폴더를 읽고 새 폴더에 저장한다. user://가 그대로 유지되는 Xogot 환경도 같은 파일을 읽는다. 기존 골드, 보유품, 검사비/감정 결과, 견적 및 잔량, 최근 거래, 누적 통계를 보존한다.

## 거래 기록

기존 last_result_text와 누적 거래/오늘 거래/최고 순이익/최대 손실을 재사용한다. 최근 완료한 **한 거래**의 매입가, 정보비, 판매가, 순이익, 거래 계획 복기, 흥정과 판매처 판단, 실제 물건 정보를 다시 볼 수 있다. 여러 거래를 검색하는 새 히스토리 시스템은 만들지 않는다. 기록이 없으면 빈 상태 안내를 표시한다. 기존 초기화 기능은 홈에서 제거하고 거래 기록 하단의 ‘새 게임 시작’으로 옮겼으며 확인 후에만 실행한다.

## 모바일 UI와 범위

390×844 기준으로 기본 Control UI만 사용한다. 이미지/캐릭터/픽셀아트, 사용자 지정 그림 그리기, 서버, 로그인, 알림, 좋아요, 채팅, 등록, 위치, 실제 시간 갱신, 장식용 검색/필터는 추가하지 않는다. 현재 매물이 세 개이므로 검색·필터는 생략한다.

모든 ScrollContainer는 세로만 스크롤한다. 긴 Label/Button은 스마트 줄바꿈, OptionButton은 폭을 늘리지 않는 말줄임을 적용한다. 팝업의 단서 선택 문구는 현재 뷰포트에 맞게 줄이고 **전체 단서와 흥정에 전달하는 원문은 유지**한다. 보유품 목록도 짧은 선택 문구와 전체 상세/툴팁을 사용한다. 하단 메뉴는 스크롤 바깥에 고정한다.
