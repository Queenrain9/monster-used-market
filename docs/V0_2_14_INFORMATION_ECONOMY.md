# v0.2.14 — Information Economy Rebalance

## 목표

정보 획득을 자동 선택이 아니라 투자 판단으로 만든다.

플레이어의 선택은 세 가지다.

1. 추가 비용 없이 현재 정보만 믿고 판매한다.
2. 싼 부분 검사를 1~2개 사서 불확실성을 조금 줄인다.
3. 높은 비용을 내고 전문 감정으로 정체와 가치 범위를 확인한다.

## 비용 공식

모든 가격은 플레이어가 이미 알고 있는 실제 매입가를 기준으로 한다.

```
reference = purchase_price

material = round50(clamp(reference × 0.02, 100, 700))
magic    = round50(clamp(reference × 0.03, 150, 900))
internal = round50(clamp(reference × 0.04, 200, 1200))
appraise = round50(clamp(reference × 0.075, 300, 2500))
```

실제 구현에서는 비율 계산 후 50G 단위 반올림과 min/max clamp를 적용한다.

## 왜 actual_value를 사용하지 않는가

숨은 실제 가치로 비용을 정하면 감정 가격 자체가 정보가 된다.

예:

- 감정비가 유난히 비쌈
- 플레이어: “이거 실제로 비싼 물건인가?”

이런 메타 추론을 막기 위해 실제 가치, rarity, state, condition은 비용 계산에서 제외한다.

## 부분 검사와 전문 감정

부분 검사는 더 싸지만 한 단서만 얻는다.

전문 감정은:

- 진품 여부
- 상태
- 희귀도
- 가치 범위
- 단서 복기

를 한 번에 제공한다.

부분 검사 비용은 이후 전문 감정 비용에서 차감하지 않는다.

따라서 “일단 전부 눌러보고 마지막에 전문 감정”이 무료 최적 루트가 되지 않는다.

## UI

감정소에서:

- 각 검사 버튼에 실제 동적 비용
- 전문 감정 버튼에 실제 동적 비용
- 전문 감정 비용의 매입가 대비 비율

을 보여준다.

표시값과 실제 차감액은 같은 엔진 함수를 사용한다.

- 전체 거래 손익에 정보 비용 반영
