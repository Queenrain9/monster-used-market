# 괴물 중고마켓 MVP v0.2.1 — Core Interaction Rewrite

## 문제 정의

v0.2에는 숨은 가치, 단서, 판매자 성격, 복수 구매자 시스템이 있었지만 플레이어의 실제 입력은 대부분 다음 버튼에 가까웠다.

`읽기 → 버튼 → 결과 → 버튼 → 결과`

v0.2.1은 새 콘텐츠를 늘리는 대신 기존 시스템을 플레이어 행동으로 전환한다.

## 장터

장터에는 매물 3개가 유지된다. 한 매물을 조사하거나 거래해도 나머지 매물은 사라지지 않는다.

각 매물은 다음 상태를 가진다.

- 미확인
- 조사 중
- 거래 중
- 구매 완료
- 포기
- 판매 완료

세 매물이 모두 포기 또는 판매 완료가 되어야 새 장터로 넘어간다.

## 조사 자원

한 장터는 조사 기회 4회를 공유한다.

가능한 조사:

- 외형 자세히 보기
- 각인 / 제작자 표시 확인
- 작동 / 마력 / 재질 상태 확인
- 판매자에게 출처 묻기
- 동종품 시세 조사

따라서 플레이어는 한 물건을 깊게 볼지, 여러 물건을 얕게 볼지 결정한다.

조사 결과는 매물 생성 시 이미 정해진 숨은 상태와 단서에서 나온다. 조사 버튼을 누르는 순간 진위나 실제 가치가 다시 뽑히지 않는다.

## 구매 전 가설

협상을 시작하기 전에 플레이어는 다음을 기록한다.

- 진품 같음 / 애매함 / 가짜 같음
- 정상 / 결함 의심
- 예상 가치 범위

가설은 구매 가능 여부를 제한하지 않으며, 거래 종료 후 실제 결과와 비교하기 위한 플레이 기록이다.

## 가격 협상

흥정은 대사 선택이 아니라 실제 가격 제안이다.

플레이어는:

1. 제안가를 슬라이더 또는 -5% / -10% / -20% 프리셋으로 정함
2. 발견한 단서 중 하나를 흥정 근거로 선택
3. 판매자의 카운터 / 수락 / 거절을 확인

실제 상태와 연결된 부정적 단서는 더 강한 협상 근거가 된다. 애매하거나 긍정적인 단서를 억지로 가격 깎기에 사용하면 효과가 약하거나 역효과가 난다.

판매자 타입별로 가격 하한과 반응 문장이 달라진다.

## 구매 후 정보 선택

구매 직후 정답은 공개되지 않는다.

추가 검사 최대 2회:

- 재질 검사: 120G
- 마력 / 반응 검사: 160G
- 내부 구조 확인: 200G

전문 감정:

- 300G
- 진위 / 희귀도 / 상태 / 실제 추정 가치 공개

플레이어는 검사비와 감정비를 아끼고 바로 판매할 수도 있다.

## 판매처 탐색

판매 단계에는 전문 구매자 2명 + 고물상 1명이 등장한다.

처음에는 전문 구매자의 성향만 보이고 가격은 숨겨져 있다.

- 전문 구매자 견적 요청: 최대 2회
- 고물상: 즉시 매입가 항상 공개

견적은 요청 시 새로 랜덤 생성하지 않는다. 판매 단계에 들어올 때 이미 생성된 가격을 공개하는 구조다.

## 결과 복기

판매 후 다음을 한 번에 확인한다.

- 실제 진위 / 희귀도 / 상태 / 가치
- 구매 전 가설 적중 여부
- 최초 희망가 대비 할인액
- 조사 단서를 흥정에 썼는지
- 검사 / 감정에 사용한 비용
- 선택한 구매자와 실제 판매가
- 이번 구매자 풀의 최고 잠재 제안과 비교
- 최종 손익

목표는 점수 자체가 아니라 다음 거래에서 단서와 판매자 성향을 더 잘 읽게 만드는 것이다.

## 저장

v0.2.1 전용 로컬 저장에는 장터 상태, 공유 조사 기회, 발견 단서, 가설, 협상, 검사, 감정, 견적 공개 여부와 결과 복기가 포함된다.
